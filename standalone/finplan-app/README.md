# Финпланирование — туристическая компания

Полностью автономный модуль еженедельного финансового планирования. Без бэкенда, без CDN. Данные хранятся в `localStorage`.

## Что внутри

6 вкладок:
- **Дашборд** — финансовое состояние компании (Кризис/Опасность/ЧП/Норма/Изобилие/Могущество), индикатор жизнеспособности по ФП №1, KPI, графики по источникам и категориям, обзор резервов.
- **Недельный план** — прогноз доходов по источникам (групповые туры, индивидуалы, экскурсии, трансферы, отели, партнёры), заявки на расходы с workflow утверждения (подана → рассмотрена → утверждена/отклонена → оплачена).
- **ФП №1** — реальная программа из 6 разделов:
  - Раздел 1: Персонал
  - Раздел 2: Базовые нужды компании
  - Раздел 3: Базовое продвижение
  - Раздел 4: Коммуникационные линии
  - Раздел 5: Базовое предоставление услуг
  - Раздел 6: Товарный счёт (отдельно)
  - Расчёт **переломной точки** (break-even) и сравнение с планом дохода
  - **Калькулятор распределения дохода** с приоритетами (базовые → просрочка → резерв → расширение) и поправками А/Б/В
  - **Пайплайн утверждения** из 4 стадий: руководители отделов → бюджетный комитет → исполнительный комитет → финансовый менеджер
  - **Пакет документов** (8 документов) с отметкой готовности
- **Резервы** — 6 типов счетов (Оборотный, Зарплатный, Налоговый, Резервный, Развития, Инвестиционный) с правилами % от валового дохода.
- **Регламент** — визуализация недельного цикла Пн—Сб с ролями.
- **Архив** — история планов + график СВД за 16 недель.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5180
npm run build    # сборка в dist/
```

## Хранение данных

Всё в `localStorage` под ключом `finplan/v1`. Кнопка «Сбросить демо» в шапке возвращает к стартовому набору.

## Стек

- Vite 5 + React 18 + TypeScript
- Tailwind CSS 3 (локальная сборка, без CDN)
- lucide-react (иконки)
- Без бэкенда — полностью клиентское приложение

## Демо-данные

Из коробки:
- 1 текущий план + 3 архивных
- 6 источников дохода с прогнозами и фактами
- 12 заявок на расходы в разных статусах
- 6 резервных счетов с балансами
- 41 строка ФП №1 по 6 разделам (включая 4 процентных отчисления от СВД)
- 16 недель истории СВД
- 8 документов еженедельного пакета
