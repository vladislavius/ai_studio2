# Модуль «Финансовое планирование» — материалы и приложение

## Что это
Адаптация классической серии писем по финансовому планированию организации в материал для **современной светской туристической компании**. Из источника полностью убраны:
- упоминания религии, церкви, миссии, прихожан;
- упоминания Хаббарда и саентологии;
- специфические термины (БАФ, ИП ОХС, шляпа, ПИН, кейс, одитинг, преклир и т.д.);
- ссылки на исходные номера регламентов как обязательные.

Сохранена и переведена на современный деловой язык **методология финансового планирования**: ответственность, недельный цикл, резервы, источники дохода, заявки на расходы, банковские сверки, формула «Резервы / Счета к оплате».

## Структура
- `source/` — исходный OCR-текст (опционально, для аудита).
- `reworked/chunk-1.md … chunk-6.md` — переработанные статьи (всё содержание 99 страниц источника, разделённое на ~40 деловых статей), каждая с разделами:
  - **Источник** (для трассировки),
  - **Суть** — главная идея,
  - **Принципы**,
  - **Применение в еженедельном финпланировании** для турфирмы.
- `db_schema.sql` — схема таблиц для Supabase (применить отдельно через SQL-редактор).
- `../../components/FinPlan.tsx` — React-модуль приложения (вкладка «Финпланирование»).

## Базовые принципы (сквозная сводка из всех чанков)
1. Финансовое планирование — это способ обращения с деньгами и активами компании ради превышения дохода над расходами.
2. Ответственность несёт **исполнительный комитет**. Он действует по **рекомендациям бюджетного комитета**, который получает **заявки от руководителей отделов**.
3. Платёжеспособность = (Резервы) / (Счета к оплате). Чем больше коэффициент — тем устойчивее компания.
4. **Резервы наполняются ДО операционных расходов**. То, что попало в защищённые счета, нельзя тратить на текущие нужды.
5. Каждая заявка на расход требует обоснования, привязки к департаменту и ценному конечному продукту.
6. Неутверждённые заявки не оплачиваются. Все платежи — только по утверждённым позициям финплана.
7. Раз в неделю проводится банковская сверка и обновляется отчёт по платёжеспособности.
8. Тренд статистик важнее, чем значения отдельных недель. Не управляйте делами по одной точке.
9. Состояние «Изобилие» = оплатить все счета и инвестировать в средства производства. Состояние «Чрезвычайное» = усилить продвижение, экономить, готовиться к спросу.
10. Никогда не передавайте и не принимайте ложную статистику валового дохода.

## Регламент недели (адаптированный)
| День | Этап | Кто отвечает |
|---|---|---|
| Понедельник | Сбор заявок и прогноза дохода | Руководители отделов + Финансовый менеджер |
| Вторник | Рассмотрение бюджетным комитетом | Главы департаментов |
| Среда | Утверждение исполнительным комитетом | Руководство компании |
| Четверг | Исполнение платежей | Финансовая служба |
| Пятница | Завершение платежей и сбор поступлений | Финансовая + Коммерческая службы |
| Суббота | Сверка с банком и закрытие плана | Финансовый менеджер |

## Терминологические замены (применены сквозно)
| Источник | Перевод |
|---|---|
| Л. Рон Хаббард / Основатель | удалено |
| ИП ОХС, ОХС | внутренний регламент |
| саентология, церковь, миссия, прихожане | компания, клиенты |
| БАФ (Банковский Администратор Флага) | финансовый менеджер |
| шляпа | должностная функция |
| исполнительный совет | исполнительный комитет |
| рекомендательный совет / комитет ФП | бюджетный комитет |
| ПИН (потенциальный источник неприятностей) | сотрудник в зоне риска |
| кейс, этика, оверт | бизнес-аналоги (дела, дисциплина, провал) |
| одитинг, преклиры, курсы | турпродукты, экскурсии, обслуживание |
| строительный фонд | инвестиционный фонд |
| Сент-Хилл, Морская организация | удалено |

## Возможности приложения (`FinPlan.tsx`)
- **Дашборд:** показатель платёжеспособности с автоопределением состояния (Кризис / Опасность / ЧП / Норма / Изобилие / Могущество), KPI, графики по источникам дохода и категориям расходов, обзор резервов.
- **Недельный план:** прогноз доходов по источникам (туры, экскурсии, трансферы, отели, партнёры…), заявки на расходы с приоритетами и статусами, workflow утверждения, кнопка перехода между фазами недели.
- **Резервы:** счета по типам (Оборотный, Зарплатный, Налоговый, Резервный, Развития, Инвестиционный), правила распределения процентов от валового дохода, целевые и неснижаемые остатки.
- **Регламент:** визуализация недельного цикла с шагами, ролями и описаниями.
- **Архив:** история закрытых недельных планов.

## Подключение
1. Применить `db_schema.sql` в Supabase SQL-редакторе.
2. Перезапустить приложение — пункт меню **«Финпланирование»** появится автоматически.
3. В оффлайн/демо-режиме модуль работает с демо-данными.
